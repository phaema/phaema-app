# Security

## Reporting a vulnerability

Please report security problems privately by email to **stuart@phaema.co.uk**, not in a public issue.

Include what you found, how to reproduce it and which version or commit you tested. You will get an
acknowledgement within five working days. Please give us reasonable time to fix the problem before
publishing anything about it.

## Supported versions

PHAEMA is in alpha. Fixes are made on the `main` branch; councils running PHAEMA should update with
`./phaema.sh update`.
