# Reminders and calendar

## Email reminders

PHAEMA emails each person a single digest of the events assigned to them that are coming up. How far ahead
reminders are sent is set by an administrator in [settings](settings.md#reminders). The defaults are:

| Event | Reminders sent (days before) |
|---|---|
| Rent review | 180, 90, 30 |
| Break notice deadline | 180, 90, 30, 7 |
| Break date | 30 |
| Lease expiry | 365, 180, 90 |
| Other | 30, 7 |

Each reminder is sent once. If PHAEMA was not running on the exact day, only the most recent reminder point is
sent, so you do not receive a burst of old reminders.

Every Monday, people are also reminded of their **overdue** events, unless an administrator has turned this off.

Reminders go to the email address on your user account. If you are not receiving them, ask an administrator to
check your email address and that PHAEMA's email settings are set up.

## Your calendar

Select **Events**, then **Calendar**, to get a private web address for your events. Subscribe to it in Outlook
(Calendar, Add calendar, Subscribe from web) or any calendar app. Your open events then appear as all-day entries
and stay up to date.

- Tick **Include everyone's events** to see all open events, not just yours.
- The address works like a password. If it has been shared, select **Make a new address**; the old one stops
  working.
- Calendar apps can only reach PHAEMA once it is running on a server reachable from the internet.
