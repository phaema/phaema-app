# Accessibility statement for [council name] PHAEMA

This is a template in the format of the GOV.UK
[sample accessibility statement](https://www.gov.uk/government/publications/sample-accessibility-statement). Public
sector bodies must publish one for each website or application they run, including staff-only ones, under the Public
Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018. Check PHAEMA on your own
installation before publishing, and replace the parts in square brackets.

---

This accessibility statement applies to [address of your PHAEMA, for example https://phaema.example.gov.uk], the
property and estates system used by [council name] staff and the people they work with.

This website is run by [council name]. We want as many people as possible to be able to use it. For example, that
means you should be able to:

- change colours, contrast levels and fonts: PHAEMA has light, dark and high-contrast themes and four text sizes
- zoom in up to 400% without the text spilling off the screen
- navigate most of the website using just a keyboard
- navigate most of the website using speech recognition software
- listen to most of the website using a screen reader (including the most recent versions of JAWS, NVDA and
  VoiceOver)

We've also made the text as simple as possible to understand. PHAEMA is built with the GOV.UK Design System, which is
tested with assistive technologies.

## How accessible this website is

We know some parts of this website are not fully accessible:

- the maps cannot be used without a mouse or touch screen; the same information is in the property lists and pages
- the stacking plan of a building's floors uses colour blocks; the table under it gives the same information
- scanned PDF documents may not be accessible to screen readers, although PHAEMA reads their text so it can be
  searched
- letters and reports downloaded as Word documents may not have the structure a screen reader needs
- [anything your own checks find]

# Accessibility statement for the [council name] tenant portal

Use this second statement only if the council switches on the tenant portal. The portal is used by the public (the
council's tenants and their staff), so it needs its own statement, published where tenants can find it, for example
linked from the portal's sign-in page and the council's website. Check the portal on your own installation, ideally
through an independent audit, before publishing, and replace the parts in square brackets.

---

This accessibility statement applies to the tenant portal at [address, for example
https://phaema.example.gov.uk/tenant/], where [council name]'s tenants see their rent account, documents, repairs,
requests and messages.

This website is run by [council name]. We want as many people as possible to be able to use it. For example, that
means you should be able to:

- zoom in up to 400% without the text spilling off the screen
- navigate the website using just a keyboard
- navigate the website using speech recognition software
- listen to the website using a screen reader (including the most recent versions of JAWS, NVDA and VoiceOver)
- use it on a phone

We've also made the text as simple as possible to understand. The portal is built with the GOV.UK Design System,
which is tested with assistive technologies. It has no maps or charts.

[AbilityNet](https://mcmw.abilitynet.org.uk/) has advice on making your device easier to use if you have a
disability.

- documents the council shares with you, such as scanned leases, may not be accessible to screen readers
- sign-in codes are sent by email; if you cannot use email, contact us to agree another way to get your
